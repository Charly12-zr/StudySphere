\# 🚀 StudySphere



StudySphere is a full-stack web application that allows users to register, log in, manage their profile, and create personal tasks in a secure and modern dashboard interface.



\---



\# ✨ Features



\- 🔐 User authentication (Register / Login)

\- 🛡️ JWT secure authentication

\- 👤 User profile system (bio + avatar)

\- 📝 Task management per user

\- 🎨 Modern animated UI (glassmorphism + gradients)

\- 🔗 Full frontend ↔ backend integration

\- 💾 SQLite database storage



\---



\# 🛠️ Tech Stack



\## Frontend

\- HTML5

\- CSS3 (animations + glassmorphism)

\- JavaScript (Fetch API)



\## Backend

\- Node.js

\- Express.js

\- SQLite3

\- JWT (authentication)

\- bcrypt (password hashing)

\- CORS
